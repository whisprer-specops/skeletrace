# Code of conduct

Treat contributors and users respectfully. Discuss code, evidence and design
choices constructively. Make room for different levels of experience and give
clear, actionable feedback.

Harassment, threats, discrimination, targeted insults and publication of another
person's private information are unacceptable. Do not include credentials or
private investigation data in project discussions.

Raise conduct concerns privately with the project maintainer through an established
project contact channel. The maintainer may moderate discussions or restrict
participation to protect contributors. Apply the same standards in issues,
reviews, documentation and other project spaces.
